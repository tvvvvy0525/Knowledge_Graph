# 开发指南与注意事项

## 数据库连接配置
- Neo4j连接信息在[application.yml](cci:7://file:///d:/kownledgeEngineering/bh/PineWilt_kg_7/pinewilt-backend/src/main/resources/application.yml:0:0-0:0)中配置
- 默认使用bolt协议，端口7687
- 请确保Neo4j服务已启动

## 数据模型
- 所有节点使用`Entity`标签
- 节点类型通过`type`字段区分（对应Java对象中的`category`）
- 关系使用`RELATED_TO`类型，通过`type`属性区分具体关系
- 节点属性：
  - `name`: 节点英文标识符
  - `label_zh`: 节点中文标签（对应Java对象中的`label`）
  - `type`: 节点类型（对应Java对象中的`category`）
  - `description`: 节点描述（可选）

## API使用说明
### 1. 获取初始图
- 路径: `GET /api/graph/init`
- 返回: 所有疾病节点
- 返回格式:
  ```json
  [
    {
      "id": 1,
      "name": "PineWiltDisease_Instance",
      "label": "松材线虫病实例",
      "category": "Disease",
      "description": null
    }
  ]
  ```

### 2. 获取邻居节点
- 路径: `GET /api/graph/neighbors/{id}`
- 参数: 节点ID
- 返回: 邻居节点关系信息
- 返回格式:
  ```json
  [
    {
      "id1": 1,
      "id2": 2,
      "name": "HAS_SYMPTOM",
      "label": "HAS_SYMPTOM"
    }
  ]
  ```

### 3. 搜索节点
- 路径: `GET /api/graph/search?q=关键词`
- 支持中英文搜索（同时匹配name和label_zh字段）
- 返回格式同初始图接口

## 开发注意事项
1. 添加新节点时，必须包含以下字段:
   - `name`: 英文标识符（必填）
   - `label_zh`: 中文标签（必填）
   - `type`: 节点类型（必填，如Disease, Symptom等）
   - `description`: 节点描述（可选）

2. 关系类型使用英文全大写，下划线分隔
   - 例如: `CAUSED_BY`, `HAS_SYMPTOM`, `TREATED_BY`
   - 关系类型会原样返回给前端，作为关系的`name`和`label`

3. 性能优化:
   - 已为`name`和`label_zh`字段创建索引
   - 已为`type`字段创建索引
   - 大数据量时考虑分页查询

4. 错误处理:
   - 200: 请求成功
   - 400: 请求参数错误
   - 404: 资源未找到
   - 500: 服务器内部错误
   - 错误信息会包含在响应体的`message`字段中

## 常见问题
1. 连接失败:
   - 检查Neo4j服务状态
   - 验证`application.yml`中的认证信息
   - 检查网络连接和端口配置

2. 查询超时：
   - 检查是否缺少索引
   - 优化Cypher查询
   - 考虑分批处理大数据集
